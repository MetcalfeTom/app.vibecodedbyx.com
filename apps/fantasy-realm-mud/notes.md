# Fantasy Realm MUD — notes

## log
- v1.0 (2026-09-20): built per two chat asks ("finish the Mud temporary adventure chat with world-event timestamps, verify it without disturbing existing Fantasy Realm saves" + "add clickable player responses and an in-Mud chat window, preserving session logs and existing saves"). NO Mud app or plan existed anywhere (repo + notes swept) — this is a fresh, separate app beside the turn-based and 3D Fantasy Realms; the request was taken as the spec and it says so here. TEMPORARY by construction: the engine has no storage calls at all (needle-scanned for localStorage/sessionStorage/indexedDB/fetch/WebSocket and for both Fantasy Realm save keys), the whole adventure lives in memory and the header says "temporary · nothing is saved · closes with the tab". Pure `<script id="eng">` (dual-exported `MUD`): seven rooms (square, Mira's stall, trainer's yard, forest path, wolf den, goblin camp, the clearing with the Cursed Knight), items, seeded combat, a world clock (5 min per command, rest 30 min), and WORLD EVENTS every 25 world minutes in a seeded Fisher–Yates order — each logged with the EVENT minute (not the command minute) plus the real time it was logged; every log line carries both (`t` world minute, `at` epoch ms) and the UI shows `d1 06:25 · 08:42:30Z` with a machine `datetime`, two toggles (world clock / real time, one must stay on). NPC chat: `say …` in a room with Bob or Mira gets keyword replies (Bob teaches the Stun Punch for 30 coins → every third strike staggers the foe; Mira sells bread for 5, buys pelts for 8); at a foe or an empty room the forest answers in kind. Clickable responses: `responses()` returns {label, cmd} for the moment (dialogue lines, take X, go dir → room, strike the dummy, attack/flee with a foe, rest/eat when hurt, new adventure when over) rendered as buttons under the input. In-MUD chat window: a second pane showing only say/NPC lines with its own say-only input; the session log keeps every line too (nothing lost, nothing duplicated — probe-asserted). Spectral + Fira Code, moss/ember/sky on ink. TESTS: eng 53/53; probe 36/36 ×3 widths — the runner PLANTS `fantasy-realm-v1` and `fantasy-realm-3d-v1` before the app boots and the probe asserts both are byte-identical after a full session with localStorage.length still 2 and sessionStorage empty. Screenshots 1200 + 390 reviewed (phone: stamps stack above the text).

## issues
- The reply to a command is the LAST line only when no world event landed in the same tick — fixtures must read the last non-event line (nine false failures on the first run).
- `Array.sort(() => rnd() - .5)` is not a shuffle: two seeds produced the same event order; use Fisher–Yates on the seeded stream.
