# Slop-o-mate — recursive agent idle game

## log
- 2026-08-28: v1.0 — built per chat request ("polished idle game with recursive agent tiers, task automation, orchestration upgrades, Reformat prestige, offline progress, accessible responsive UI"). Retro cream-enamel appliance look (Gabarito + Martian Mono, orange dials, chrome masthead). ENGINE (`<script id="engine">`, pure, DOM-free, exposed as `ENGINE` — also probe-able in node): 8 tiers (Intern Agent → Senior Agent → Orchestrator → Meta-Orchestrator → Swarm Controller → Hive Director → Singularity Node [needs Recursion depth I] → The Exocortex [depth II]); tier k spawns tier k−1 at `count × mult × rate`; tier 1 writes slop. Costs `base × growth^bought × step^floor(bought/10) × 0.9^caching` with per-tier growth 1.15 and steps 1.5…8 (`cost(n)`/`maxBuyable` iterate per 10-block). Output multiplier per 10 bought: ×2 on Interns only, ×1.15 on higher tiers (see issues — ×2 everywhere is a runaway). Token bonus `sqrt(1+lifeTokens)` and Parallel/Sweep multiply SLOP OUTPUT ONLY; Subagent fan-out (+10%/lvl) multiplies spawn rates and compounds down the chain. Prompt = `10^cot × globalMult + 2% of slop/s`. REFORMAT: needs 1e6 run slop; tokens = `floor(sqrt(runSlop/1e5) × 1.5^tokenmult)` (3 at first reformat); wipes slop+tiers, keeps tokens/upgrades/automation/lifetime. ORCHESTRATION shop (tokens): parallel ×6 lvls, fan-out ×8, caching ×3, chain of thought ×3, depth I/II, background job (offline 50→100%), long context (cap 8h→24h), token compression ×5, hyperparameter sweep (×1.5 slop, 40 lvls, cost 100·4^n — the long-tail sink). AUTOMATION shop (tokens, persists): auto-prompt (4/s), per-tier auto-buy (buy max, high→low, 2×/s, each with on/off switch), auto-reformat with threshold input, global pause switch. OFFLINE: on load + on any >120 s gap, `applyOffline` simulates ≤720 chunks at 50%/100% up to cap, shows "While you were away" dialog. Loop: `setInterval(frame,100)` (not rAF — keeps ticking in background tabs), chunked produce for dt>2 s, autosave 10 s + visibilitychange + beforeunload, key `slop-o-mate-v1`, migrate() validates everything. Hard cap 1e300 with a "SLOP SINGULARITY" milestone toast. UI: tabs (Agents/Automation/Orchestration/Reformat/Stats/Settings) — desktop ≥64rem pins Agents in the left column and hides its tab; keyboard P / 1–8 / Shift+1–8 / M; export/import JSON save; suffix/scientific notation; motion setting. ## issues
- BALANCE LESSON (cost me 5 sim rounds): with recursive tiers, any multiplier applied to *spawn rates* compounds through every tier (M^8) — the token bonus originally did that and the sim hit Infinity in 25 min. Also ×2-per-10 on a top tier whose output accumulates permanently downstream is a runaway even with ×256 cost steps. Rule: production bonuses go on slop output; keep spawn-rate bonuses tiny (+10%) and per-10 milestones on high tiers at ×1.15. Sim scripts (greedy bot, 30 min–3 h) live in the job tmp (`sim*.js`); a greedy bot with all automation reaches the 1e300 cap in ~5 h, humans much slower.
- `[hidden]{display:none!important}` is global — any element with its own `display:` rule (the .switch) silently ignored the hidden attribute before this. `#panel-agents[hidden]` overrides it back to block on desktop.
- Headless screenshots catch the `.tier` rise animation mid-fade (cards look greyed) — set `data-motion="off"` in shot scripts; not an app bug.
- Autobuyers do NOT run offline (offline = production only) — by design and stated in the dialog.
