// hdd vs ssd placement

⚡ SSD

  • OS + applications
  • projects you're editing now
  • anything you open twice a day

costs more per TB, but recovery and daily work are fast; shrugs off bumps.

💿 HDD

  • photo + video libraries
  • finished-project archives
  • the backup copies themselves

cheapest per TB by far — perfect for copies that mostly sit and wait.
