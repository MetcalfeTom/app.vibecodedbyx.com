Controls & rules
  • ↑↓←→ or WASD steer the Snake. In 2-player mode the Snake uses WASD and the Serpent uses the arrow keys. On touch, use the d-pads or swipe the track.
  • Pass the gates in order (1 → 2 → 3 → finish) for a lap. Three laps wins.
  • Apples: +2 length and a short boost. Chevrons: a boost. A long tail is a wall for everyone — including you.
  • P / Esc pause · R restart · M mute · Enter start
