    why we teach this

    Steganography — hiding messages inside ordinary files — is a real technique with honest uses (watermarking, research) and dishonest ones. This game teaches detection: the diff views, bit lamps and channel isolations here are baby versions of real steganalysis, which adds statistics on top. Every "secret" in this file is a harmless fruit-and-weather word drawn by the game itself. Nothing here links out, uploads, or hides anything in your files.
