How it squishes

Every block carries the weight of everything stacked above it. Soft blocks squish under that weight, solid ones don't. Use all the blocks and land the top of the tower inside the pink band.

    Keys: 1–9 drop a block · Backspace takes the top one off · H hint · R restart · N next level
