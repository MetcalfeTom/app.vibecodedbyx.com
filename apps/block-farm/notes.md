# Blockfarm — notes

## log
- v1.0 (2026-09-16): Built per chat ("Minecraft-like farming game with planting seeds, watering soil, harvesting crops, and selling produce — prioritize a playable first version"). No dedicated farm game existed (block-world is a voxel sandbox with a few crop mentions; neon-harvest is a growth-cycle toy). Chunky 2.5D canvas farm, 12×9 blocks drawn as cubes (top face + front face, board translated down by the cube depth so row 0 is not clipped): grass, tilled dirt (dark when wet), pond top-right, rocks top-left, market stall bottom-left, farmer with a red hat and a facing marker. `<script id="eng">` = pure node-testable: one verb `use(x,y)` on an adjacent block with the selected tool — hoe tills grass, can waters dirt/crops (8 charges, refills on the pond), seeds plant on dirt, any tool harvests a ripe crop (wheat/carrot ×2, pumpkin ×1), the stall opens the shop; crops advance stages only while the dirt is wet (wet lasts 50 s, wheat 14 s/stage, carrot 22, pumpkin 32, three stages), growth within a tick is capped to the seconds the dirt stayed wet (large-dt safe); day counter every 90 s; sell all (3/5/12) and buy seeds (1/2/5); start 10 coins + 5 wheat seeds; snapshot/restore with a broken-save fallback. Controls: WASD/arrows walk one block, E/Space use the tool on the faced block, 1–5 pick a tool, tap an adjacent block to use the tool there (a far tap steps toward it), touch d-pad + USE on coarse pointers, shop dialog (Escape closes, keys ignored while open), autosave every 5 s + on every action, "new farm" with confirm. Tiny5 title + Chakra Petch.
- Verified: engine 44/44 node (world layout, walkability, facing, full till→water→plant→grow→harvest loop with timings, dry pauses growth, can empties/refills, seeds run out, buy/sell arithmetic, misuse messages, day/counts/snapshot/broken save, hygiene); browser 42/42 at 1200/390/320 (canvas paint check for grass/pond/hat, key walking, E/Space/hotbar/digit keys through the real handlers, ripe wheat drawn gold on its block, harvest to HUD, pointer tap on an adjacent block + far tap steps, pad buttons, empty can + pond refill, shop open/sell/buy/disable/Escape, keys blocked while the shop is open, persistence round-trip, ≥44px, a11y, no overflow); screenshots both widths.

## issues
- Big-dt growth: advancing one stage per tick AND decrementing wetness before the growth check made a 40 s seam step grow nothing — growth now loops stages and uses min(dt, wet-before). Real play never hit it (dt clamped to .25) but tab-away catch-up would have.
- rAF's first timestamp can be BELOW a performance.now() taken at script start under virtual time → negative dt → day 0. Clamp dt ≥ 0 in the loop and in tick().
- Probe fixtures: the shop re-renders its rows on every purchase (re-query buttons); KeyboardEvent key must be 'Escape' exactly; a watering loop across the top rows hits the pond and refills.
- Tiny5 digits read as dotted glyphs at small sizes — HUD numbers use the body font.
