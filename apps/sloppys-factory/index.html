        ⚠ Floor rule: the sandbox

        The whole floor sits in a sandbox. Routine work (edit a file, run a test) goes ahead without anyone clicking "allow", while a safety check still blocks risky actions. That's how the factory runs on its own: autonomy = a sandbox + guardrails + an undo button (git), not "approve everything".

                                      The skill shelf
                                      
  
                                      A skill is a markdown file of craft that an agent takes off the shelf when a job needs it. In Claude Code each one lives in .claude/skills/<name>/SKILL.md, and its first lines say when it applies, so the agent picks it up by itself. These are my own write-ups of the seven I reach for most, ready for your factory. Each one ends with the trap behind its main rule.

                                              Flax's brief: build the factory first, then give every station its own file that tells the agent exactly what to do there. Not one example, but a general kit for your own factory. Station 0 is the floor plan, stations 1 to 8 run the line, the reject bin is for when something breaks live, and the ready-made files go straight into your project.

                                                    How to use it: set up everything in station 0 first. Then copy the station files into .claude/commands/ in your project, and in Claude Code each one becomes a command you type, like /intake or /plan. With an agent that has no commands, paste the file in as a prompt. Together with starter.md as your agent's instructions, that's the whole factory.
