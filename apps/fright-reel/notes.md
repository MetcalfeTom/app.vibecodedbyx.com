# Fright Reel — notes

## log
- v1.0 (2026-09-17): Built per chat ("safe canvas spooky video maker with animated scenes, captions, sound cues, and export controls"). Kurzfilm is a general caption/look/beat recorder; this one is scene-based and spooky, so it is its own app. "Safe" = no camera/mic/screen capture/network (probe-scanned needles), nothing gory (the static scene's face is an outline), a "gentle flashes" toggle ON by default that damps the lightning strobe and the static face flash, and the save link is the only way a file leaves the page. `<script id="eng">` = pure project model: 6 scenes (haunted house, graveyard, dead forest, full moon, cursed hallway, static), 7 cues (none, thunder, ghost wail, church bell, heartbeat, creaking door, wolf howl), 3 caption styles (whisper fade, typewriter, scream slam), clips {scene, dur 1–10, caption ≤80, style, cue, cueAt 0–1}, ≤12 clips, normalize() with fallback to a 4-scene sample film, clipAt(t) with the last clip owning t = total, cueList(), captionState(), script(). Scenes are procedural canvas draws (lightning with a gentle mode, lit window flicker, fog, rising ghost, bats, clouds crossing the moon, a wolf, a corridor whose candle dies at 70 %, a static channel). Cues are synthesised WebAudio, fired once per play pass at absolute times; cue select previews the cue. Exports: WebM via an offscreen canvas captureStream(30) + MediaRecorder (vp9/vp8 fallback) with the audio bus routed through a MediaStreamDestination so cues are in the file, progress bar, blob URL on a save link; PNG poster at the chosen size; script text copy (clipboard raced with a 900 ms timeout, fallback shows the text). Rubik Wet Paint + Overpass Mono, pumpkin on violet-black.
- Verified: engine 26/26 node (data, totals/starts, clipAt boundaries and clamps, cue list order, makeClip clamps every field, normalize fallbacks and cap, add/move/remove rules, caption styles, script text, hygiene); browser 39/39 at 1200/390/320 (targets, list + editor binding, EVERY scene paints, reset, seek/scrub, typewriter caption painted, play fires the 4 cues once each and ends, restart, Space, editing every field with list/total updates, reorder/add/remove, persistence, gentle default, poster PNG decodes at 640×360, copy script status, MediaRecorder starts + locks the button, a real webm blob comes back with a blob: save link); screenshots both widths.
