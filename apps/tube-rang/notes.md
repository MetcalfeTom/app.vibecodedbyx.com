# Tube Rang — CRT wall-jump + boomerang platformer

## log
- 2026-08-28: v1.0 — built per public request ("standalone vanilla JavaScript canvas platformer prototype with wall-jumps, boomerang magic, CRT pixel visuals, and keyboard controls"). Zero dependencies, one file. 320×180 internal buffer drawn to a canvas inside a CSS CRT bezel (Sloptron 2000): scanline + RGB-mask overlay, vignette, glass highlight, flicker + rolling bar (killed by prefers-reduced-motion), power-on scaleY animation on start, `filter:saturate/contrast/brightness` on the canvas for phosphor pop. Tiny5 + VT323. ENGINE is a pure `<script id="engine">` block (`ENGINE`, node-loadable via `new Function`): 8px tiles, 6×10 player, sub-pixel 1px-substep AABB collision, one-way `-` platforms (down+jump drops through, 10-frame ignore), spikes `^` with an inset hitbox, doors `D` solid until any switch `S` is hit, gems `*`, patrolling slimes `o` (edge/wall turn), checkpoints `C`, finish `F`, out-of-map = solid. PLAYER FEEL: acc .22 / air .14, max 1.8, friction .28, ground turnaround ×2, gravity .28 (+.32 while jump released = short hop), jump 4.6 (≈38px, 4.7 tiles; running jump ≈7.6 tiles, standing ≈6), coyote 6, jump buffer 6, wall slide 1.1 when pressing into a wall, wall jump vx 2.6 / vy 4.3 with 9-frame lockout + 6-frame wall coyote, over-max vx decays (0.4 ground / 0.16 air). RANG: X/K/Shift throws in facing dir (hold Up/Down to aim vertically; down only in the air), speed 4.2 decel .09 (≈98px reach) then homes back (2.6→5.5), catch radius 7, bounces off solids on the way out, passes through everything on return, X again = early recall, one in flight at a time. Kills slimes, collects gems, flips switches (opens all doors). Deaths respawn at the last checkpoint after 45 frames with slimes reset, gems kept, door stays open. 3 hand-made sectors: BOOT SECTOR (74×22, tutorial: gap, slime, one wall-jump shaft), FIRMWARE (80×23: floating crystal only reachable with an upward throw opens the door, staircase over a spike bed, a spike-bottomed shaft, one-way descent, finish tower shaft), KERNEL (50×36 vertical: right-column climb, switch + 4-tile door, sealed left climb, 2-wide shaft to the top deck). Hints are per-level `{x,y,t}` labels that fade with distance. HUD + all text drawn with a built-in 3×5 pixel font. Title has level select (1/2/3, unlocked progressively), best time/gems per sector in localStorage `tube-rang-v1` (also mute). Web Audio synth SFX (jump/wjump/throw/catch/bounce/gem/kill/switch/die/cp/clear/won), M or footer button mutes. Loop = fixed 60Hz accumulator on rAF + 50ms timeout fallback; window blur pauses. Touch bar (◀ ▶ ▲ RANG JUMP) shows under `(pointer:coarse)`. A11y: skip link, single h1, canvas role=application w/ control summary, aria-live status for sector/gem/checkpoint/death/clear, 44px targets, focus-visible, rem units. Test seam `window.__X` = {G,E,held,pressed,freeze,step(n),fit}. Probes: node engine 47/47 + route bot 8/8 (every shaft climbable by a wall-aware bot, every gap under max jump), headless desktop 46/46, mobile 11/11, screenshots reviewed.

## issues
- Level geometry lessons from the node route bot: (1) a switch that must be hit from below cannot sit on a ledge — the rang bounces off the ledge first (fixed: L2 crystal floats). (2) A shaft entrance under a wall needs the wall bottom ≥ full-jump apex (~5 tiles) above the floor, or a full jump wall-slides down and lands on whatever is under the wall (L2 finish tower: wall 67 now ends at row 12, spikes narrowed). (3) Two ledges 2 rows apart overlap a 10px-tall player (L3 switch ledge moved sideways).
- Levels are authored in a coordinate "painter" (job tmp `paint.js`) and spliced as ASCII into `const LEVELS` — trailing spaces are trimmed; missing cells = empty, off-map = solid. Keep the ASCII readable; re-splice with a count-checked script, never hand-edit rows of different lengths.
- Screenshots catch the entrance animations (header fade, CRT power-on line) — inject `*{animation:none!important}` in shot pages; not an app bug.
- Node `console.log(number)` inside `$(…)` emitted ANSI colour codes and corrupted a `const PORT=` sed; use `process.stdout.write(String(p))` in port pickers.
- Headless has `pointer:fine`, so the touch bar is force-shown in the mobile probe; real phones get it from the media query.
