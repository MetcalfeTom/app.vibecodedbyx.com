# Paper Squall — paper plane vs. the storm

## log
- 2026-08-28: v1.0 — built per public request ("polished paper-airplane arcade: dodge lightning, collect wind boosts, chase high scores"). One-button flight: hold (pointer / Space / ↑ / W) = lift, release = glide down; pitch angle follows vy. World scrolls left at 260→450 u/s over ~2.2 km (`difficulty()` = dist/2200 capped). HAZARDS: cloud-to-ground bolts (gap BELOW → dive), ground streamers (`up:true`, gap ABOVE → climb), cloud-to-cloud arcs (horizontal, go over/under), ball lightning orbs after 500 m (drift, bounce vertically). Bolts/arcs are DISTANCE-TRIGGERED, not timer-triggered: each spawns with a `trigger` (px ahead of the plane at which it fires, ~90–230 + speed×0.15) so fairness is identical on any screen width; `life` 0.55–0.7 s means short-trigger bolts are still live when you arrive (use the gap) while long-trigger ones expire first (wait it out) — probe measured 28 live / 12 expired over 40 spawns. Warn phase = red dashed line + pulsing source glow (pulse rate rises with proximity) + crackle SFX 0.4 s before strike. GUSTS: 🌀 spiral glyphs, single or trio; collect → +60×(1+streak), streak up to ×10 multiplier on distance score (decays after 6 s without a gust), 2.6 s tailwind (speed ×1.55, cyan trail, 1.5× score). Near-miss +25 when a bolt was live as you passed. One hit = crumple (26 paper-bit burst, flash, shake unless reduced-motion). SCOREBOARD: localStorage best + Supabase table `paper_squall_scores` (player/score/distance/gusts, no id column — the "you" row highlight keys on user_id+created_at); board offline → friendly "scores stay on this device" line, submit failure never loses the local best. AUDIO: Web Audio only — paper flutter loop (bandpassed noise, gain/frequency follow speed via setTargetAtTime), thunder (lowpass noise + sub sine), crackle, gust whoosh + rising streak arpeggio, crumple, takeoff; M or ♪ toggles, persisted. A11Y: `<main>`, canvas role=application w/ control summary, dialogs role=dialog aria-modal + aria-hidden toggling, aria-live status (updated on events only), 44 px targets, focus-visible, rem-only, reduced-motion kills shake/rain-heavy/chip wobble. Narrow screens (<700 px): plane sits at 20 % instead of 27 %, top speed ×0.88, shorter triggers. Fonts: Cabin Sketch + Patrick Hand + IBM Plex Mono; graph-paper sky that darkens with the storm, ink-outlined crosshatched clouds (stroke-then-fill for a clean union outline).
  - Suite (headless chromium via same-origin iframe wrapper + `window.__SQ` seam with `freeze()`): 42/42 — physics (gravity/lift), score accrual, gust→streak/boost/chips, tailwind speed, streak decay, bolt lifecycle + distance-trigger fairness + live/expired mix, every collision kind (bolt gap below/above, arc on/off height, orb, floor), retry reset, keyboard guards (Space inside the name input ignored), mute persistence, best persisted, zero window errors.
  - Probe lesson: harness-injected bolts lacking `trigger` produced `rgba(...,NaN)` → `addColorStop` threw and the plane "vanished" from screenshots. App now guards `(b.trigger||0)` and `|| 0` on the pulse factor. Screenshots catch what logic probes don't — keep taking them.
