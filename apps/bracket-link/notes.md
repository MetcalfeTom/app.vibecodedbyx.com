# Bracket Link

Tatum's idea (2026-10-02): a tournament bracket for an online group, no accounts.

## How it works
- The whole bracket (title, names, winners, id) is base64url JSON in the URL hash: `#b=` organizer copy, `#view=` look-only copy. The bracket itself never goes to a database; since v2.0 only slip codes do (table `bracket_link_slips`, see v2.0).
- localStorage `bracket-link-v1` keeps the organizer's last bracket; a link in the address bar wins over it.
- Single elimination, size = next power of 2, standard seeding (1 v 16, 8 v 9...), byes go to the top seeds and auto-advance.
- Winners stored per match id as a player index; layout() drops any stored winner that is no longer in its match, so undoing an early result unravels the later rounds.
- Same number of names = rename, results kept. Different count or shuffle = restart (with a confirm strip).
- Test hook: `window.__BL` (S, layout, enc, dec, clean, render, link, view).

## Look
Paper sheet taped to a pub wall: #f2eee3 paper, ink #15120e, one red marker #d7342a, gold champion. Big Shoulders Display + Spline Sans Mono.

## Issues
- Tatum wants players to report results themselves and the organizer to settle disputes, ideally with a database. Built in v2.0 with one Supabase table: visitors add and read rows, never names or brackets, only the slip code.
- v2.0 table as built: the create-table tool's default policies also let a user update/delete their OWN rows (unused by the app) and it can't add a size CHECK. The app caps codes at 400 chars on both sides, but the DB itself doesn't. Accepted as is: a slip row is a short code string, junk is ignored and rows are capped per pull.
- Anyone with the share link knows the bracket id and could insert junk or unsigned slips for it. Junk is ignored (not a BL- code for this id), unsigned slips still ask add it / ignore, caps: 80 rows per user per pull, queue of 60. Signed slips can't be forged without the personal link.
- The organizer copy only sees slips while it is open (it catches up on open). The 15-min quiet rule still starts when a slip ARRIVES at the organizer's copy, not when it was sent.
- #view copies and players never read the table; only a copy with the key does.
