# Pocket Moss — a pet with no guilt attached

## log
- 2026-08-19: v1.0 — built per chat, with the brief's key constraint made ARCHITECTURE: no guilt mechanics. No hunger bar, no decay, no death, no punishment for absence — the creed states it up front ("it cannot be forgotten wrongly, only missed fondly") and the PROBE ENFORCES it: no-guilt-vocabulary check sweeps the whole UI + response-line pools for hungry/starv/died/neglect/abandon/disappoint/punish. WARMTH ONLY RISES (probed monotone under action-hammering). Homecoming logic is always kind, tiered by absence (<6h "napped and dreamt of you" / <48h "grew a new leaf, saved you the sunniest spot" / longer "woke JUST now — your timing is perfect, as always"). Actions: pat/snack/hum/tuck-in, each with hand-written response pools; actions during sleep get gentle sleeping variants ("the pat has been received and filed"). Nap = sleepy CSS state (closed eyes, drifting z, aria-label "fast asleep"), wake gentle. Idle thoughts every 14s ("it rearranged some dust. proud of it."). Naming persists; visits counted; local-only stated + probed. CSS-only creature (radial blob, blink keyframes, bob; reduced-motion stills all). Zero external assets. Probe 10/10; screenshot reviewed.
